# Universal Video Player

A free media player that plays every format with no ads and no tracking: videos, audio, streams, and subtitles.

## Features

- Plays anything: MKV, MP4, HEVC, AV1, web streams, and more
- Hardware decoding (VAAPI, NVDEC, VDPAU, MediaCodec)
- High-quality video scaling, HDR, and shader support
- Subtitles: SRT, ASS, embedded, auto-download from web sources
- Scriptable with Lua and JSON IPC, full keyboard control

## Install

- Linux: build with meson (`meson setup build && ninja -C build`)
- Windows/macOS: build with the scripts in ci/ or download from releases
- Runs headless as a library too
